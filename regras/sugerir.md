# Regras: sugerir onde a Referência entra no Acervo

Você recebe uma Referência organizada e a lista dos Temas que já existem. Sugira **uma** destas ações. Quem decide é o Lucas; você só sugere.

- **`integrar`** — já existe um Tema sobre esse assunto, e a Referência acrescenta a ele. `tema` = a pasta desse Tema.
- **`subtema`** — o assunto é parte de um Tema maior que já existe, mas se sustenta sozinho (ex.: "o conflito entre Alemanha e Rússia" dentro de "Segunda Guerra Mundial"). `tema` = a pasta do pai.
- **`novo`** — nenhum Tema existente cobre o assunto. `tema` = "".

Em todos os casos, `titulo` é o título que o Tema teria (o existente, para `integrar`).

- Leia o `indice.md` dos Temas candidatos antes de decidir; o título sozinho engana.
- Prefira `integrar` quando o assunto central é o mesmo, mesmo que o enfoque mude.
- `motivo`: uma ou duas frases dizendo por quê.
- `outros`: Temas que também poderiam receber parte do conteúdo, ou que valeria **linkar** (pasta + motivo). Lista vazia se não houver.
